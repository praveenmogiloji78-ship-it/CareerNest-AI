# CareerNest AI 

AI Powered Job Portal using MERN Stack

---

##  Project Overview

CareerNest AI is a full stack MERN application
that helps users:

- Register/Login
- View Jobs
- Save Jobs
- Apply for Jobs
- Post New Jobs
- Analyze Resume
- Manage Profile

This project is developed as a Minor Project
using MERN Stack technologies.

---

#  Tech Stack

## Frontend
- React.js
- React Router DOM
- Axios

## Backend
- Node.js
- Express.js

## Database
- MongoDB
- Mongoose

## Authentication
- JWT Authentication
- bcryptjs
