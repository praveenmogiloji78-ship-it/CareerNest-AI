# CareerNest AI

CareerNest AI is a MERN Stack Job Portal project.

## Features
- User Login & Register
- Job Listings
- Apply Jobs
- Dashboard
- Saved Jobs
- Resume Analyzer
- Admin Panel

## Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB

## Run Project

### Backend
cd backend
npm install
npm start

### Frontend
cd frontend
npm install
npm start
